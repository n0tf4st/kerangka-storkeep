# Sampel

Bahan reproduksi bug. Simpan **teks/log**, bukan screenshot.

- `log-chat-*.txt` — potongan log percakapan bila user melaporkan bug
- `input-*.txt` — contoh input yang memicu masalah
- `spesifikasi.txt` — daftar perintah/fitur yang dijanjikan ke user

Aturan: jangan simpan data pribadi asli (id Telegram, nomor HP, email). Sensor dulu.
